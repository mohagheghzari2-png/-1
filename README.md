# 🏠 خونه‌ی من — شبیه‌ساز زندگی اول‌شخص

یه بازی سه‌بعدی داخل مرورگر گوشی: توی یه خونه‌ی مدرن راه می‌ری و زندگی روزمره‌ات رو مدیریت می‌کنی.

## بازی کردن
- **جوی‌استیک** (پایین سمت چپ): راه رفتن
- **کشیدن انگشت روی سمت راست صفحه**: نگاه کردن به اطراف
- به یه چیز نگاه کن (کاناپه، تخت، یخچال، دوش، لپ‌تاپ…) و دکمه‌ی زرد **«انجام بده»** رو بزن
- نوارهای بالا: 🍽️ گرسنگی، ⚡ انرژی، 🚿 نظافت، 🎮 سرگرمی
- هر ۱۲ دقیقه‌ی واقعی = یه شبانه‌روز بازی
- گوشی رو **افقی** بگیر

## آپلود روی GitHub (از خود گوشی)
۱. با مرورگر (Chrome/Safari، نه اپ گیت‌هاب) برو به github.com و وارد شو.
۲. دکمه‌ی **+** بالا → **New repository** → اسم بذار (مثلاً `my-house`) → **Public** → **Create repository**.
۳. **uploading an existing file** (یا Add file ← Upload files) رو بزن و این سه فایل رو انتخاب کن: `index.html`، `style.css`، `game.js` → پایین صفحه **Commit changes**.
۴. **Settings** ← **Pages** ← زیر Source گزینه‌ی **Deploy from a branch** ← Branch: `main` و پوشه‌ی `/ (root)` ← **Save**.
۵. بعد از ۱ تا ۲ دقیقه آدرس بازیت اینجا آماده‌ست:
   `https://اسم-کاربری-تو.github.io/my-house/`

> اگه دکمه‌ها توی گوشی پیدا نشد، توی مرورگر گزینه‌ی «Desktop site» رو روشن کن.

## نکته‌ها
- بازی برای بارگذاری سه‌بعدی (Three.js) و فونت به اینترنت نیاز داره.
- اگه گوشی قدیمیه و گیر می‌کنه، دکمه‌ی «کیفیت» بالای صفحه رو روی «پایین» بذار (بازی خودش هم کیفیت رو کم می‌کنه).
